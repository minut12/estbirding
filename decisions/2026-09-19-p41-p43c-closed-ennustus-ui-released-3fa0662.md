Shipped in `public/maps/linnuliigid/index.html` (+ `public/maps/shared/map-hamburger-control.js` in P43b): P41 (11ae7fb) turned the Ennustus map control into a 40px icon button with a predicted-sites badge; P42 (da86070) rebuilt the probability-cell popup (stat tiles, best-time block, 12-column month chart); P43 (62e53e8) redesigned the Tõenäosus panel per mock v4 §2 A: band chips with counts, section headers in %-sort, conic % rings, eBird/eElu/kevad meta line, status under the ring, whole row opens `__ennProb`, sort moved into a `<details>` menu, and the admin Skaneeri/Jaga buttons moved to the footer (held verbatim in hidden `#ennAdminHold` and echoed by `render()`, because `render()` rewrites `#ennFt`); P43b (64cc427) hides the map selector while the panel is open, shortens the best-period caption and stops horizontal scroll in the list; P43c (0acdf54) makes the band chips wrap (`flex-wrap:wrap`) instead of scrolling off-screen in a hidden-scrollbar row.

**Contract change:** `body.enn-open` joins `body.sidebar-open` as a SIDEBAR_STATE input — `open = enn-open || (≤900px && sidebar-open)`. `enn-open` counts at **any width** (the panel is a modal on desktop too) and is set only in `__openEnn` / removed only in `__closeEnn`; every close path (✕, backdrop, internal call) must go through `__closeEnn` or the selector stays hidden. Extends [[2026-09-18-p40-sidebar-state-contract]].

**Bands are display-only:** high ≥80, mid 50–79, low 20–49, rare <20 **including unscored** (`score===null`), applied after the existing sort via the `band` var; scores, boosts and the sort are untouched. **Caption:** the ★ status shows only the Estonian abbreviation of the *first* month in the best-period label (`28 Apr – 10 May` → `★ apr 42%`); the full label and % stay in the `title`.

Edits to escaped JS strings in this file follow [[2026-09-19-linnuliigid-unicode-escapes-in-edits]]. Released fast-forward `442e9a3..64cc427` after Kristian's main-- check, then `64cc427..0acdf54` for P43c.

## P44/P44b — eBird in Tõenäosus rows (released 3fa0662)

When a species has no admin-scan value (`p.occ7Ebird==null`), the row's eBird value now comes from `window.__ennEbirdCounts[getEbirdCode(name)]`. That map is filled by the regional eBird EE bulk (obs/EE/recent, `__refreshEbirdEEBulk`). `__openEnn` refreshes it without blocking the panel when it is ≥6h old (the same TTL as the scan gate) and re-renders once it arrives (P44, 841c5e7). **That feed holds one latest observation per species**, so the "count" is really 0/1. It is therefore shown as presence, not a count: `eBird ✓ dd.mm` (latest `obsDt` from the `bm_ebird_obs_v1` cache; ✓ with no date if the cache has no entry for it) or `eBird 0` (P44b, 3fa0662). Do not show it as a number again. **True 7-day counts are deferred:** they would need per-species eBird calls or an hourly n8n/Supabase cache. Released fast-forward `0acdf54..3fa0662`.
